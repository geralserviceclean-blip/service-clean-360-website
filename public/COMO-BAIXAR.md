## 💾 Como Baixar

### Opção 1 - Via Browser
1. Acesse: https://sb-1h4vd8djeti9.vercel.run
2. Acesse o servidor e navegue até o arquivo
3. Clique com o botão direito em `service-clean-360-website.tar.gz`
4. "Salvar como..." ou "Download"

### Opção 2 - Via Comando (se tiver acesso SSH)
```bash
# Baixar o arquivo
curl -O https://sb-1h4vd8djeti9.vercel.run/service-clean-360-website.tar.gz

# Extrair
tar -xzf service-clean-360-website.tar.gz

# Entrar no diretório
cd service-clean-360-website
```

## 🚀 Após Baixar

### 1. Extrair o Arquivo
```bash
# No Windows (use WinRAR, 7-Zip ou similar)
# No Mac/Linux:
tar -xzf service-clean-360-website.tar.gz
```

### 2. Instalar Dependências
```bash
cd service-clean-360-website
npm install
# ou
pnpm install
```

### 3. Executar Localmente
```bash
npm run dev
# ou 
pnpm run dev
```

### 4. Abrir no Browser
```
http://localhost:3000
```

## 🔧 Personalizar

### Alterar Contactos:
- Edite os ficheiros em `src/components/`
- Procure por `(+351) 999 999 999`
- Substitua pelos seus contactos reais

### Alterar Conteúdo:
- Textos: edite os componentes React
- Imagens: substitua em `public/`
- Cores: edite `src/app/globals.css`
